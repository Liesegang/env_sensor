# Card ダッシュボード描画ライブラリ

`epaper_sample` のダッシュボード描画を独立した C++ ライブラリへ移しました。
Arduino、SPI、GPIO、電源操作に依存せず、呼び出し元のフレームバッファだけを変更します。
`epaper_sample` を削除してもビルドと描画には影響しません。

## 画面

- 論理画面は横 600 × 縦 400 ピクセル。時計回りに回転し、EPD3IN6E のネイティブ 400 × 600、4 bpp、120,000 バイトへ出力します。
- 上部に温度、湿度、気圧、CO2、VOC、HCHO、NOX、照度の 8 枚のカードを配置します。
- 下部に直近 24 時間、10 分ごとの 144 点を重ねて描画します。縦軸は各系列の範囲に対する 0〜100% です。
- 5 × 7 フォント、150% 拡大、カードの閾値、線の重なり順、2 色交互の光学混色をサンプルから維持しています。

## API

`include/epd_dashboard.h` は C と C++ の両方から利用できます。

```c
static uint8_t frame[EPD3IN6E_FRAME_BYTES];
int err = epd_dashboard_demo_render(frame, sizeof(frame));
if (err == 0) {
    err = epd3in6e_refresh_frame(&display, frame, sizeof(frame));
}
```

`epd_dashboard_demo_render()` は固定の乱数シードで 24 時間分の疑似データを生成します。
HCHO も疑似データであり、実装されていないセンサーを読み取る処理はありません。
生成用の 8 系列は約 3 KiB の静的 RAM を使います。デモ関数の並列呼び出しは避けてください。

実測履歴を表示する場合は `epd_dashboard_render()` に 8 個の `epd_dashboard_series` を渡します。
`values` は古い順に並べ、`plotLow` を 0、`plotHigh` を 65535 として正規化した値を格納してください。
最新値は最後の要素です。
カードに範囲外の値も正確に表示する場合は、`has_current_value = 1` と `current_value` に有限な実測値を指定します。
この値は最新要素が有効なときにカードだけで使い、グラフの正規化済みデータは変更しません。
`has_current_value = 0` では従来どおり最後の要素をカード表示にも使います。名前は 1〜8 文字、単位は 0〜6 文字、どちらも NUL 終端が必要です。
小数桁は 0〜2、色は `epd3in6e_color` の 6 色から指定します。
プロット範囲は有限かつ `plotLow < plotHigh`、閾値は有限かつ昇順である必要があります。
不正な入力はフレームを変更する前に `-EINVAL` を返します。
実測用 API は独立した入出力バッファで並列呼び出しできます。

実測の欠測は `has_validity_map = 1` と `valid_bits` で指定します。
18 バイトのマップで、要素 n の有効ビットは `valid_bits[n / 8]` の `1U << (n % 8)` です。
0 のビットのデータは描画せず、欠測区間を線で結びません。単独の有効値は点で表示します。
144 要素未満の履歴は右詰めし、収集前の左側を欠測にしてください。
最新要素が欠測ならカードは `--` と `NA` を表示します。
未実装の HCHO などはマップをすべて 0 にすることで欠測として扱えます。
VOC/NOX インデックスの単位は、呼び出し元で `unit = "IDX"` と設定します。
`has_validity_map = 0` は全要素有効として扱うため、既存のデモと表示結果は変わりません。
マップと最新値追加による RAM 増加は 8 系列で約 0.2 KiB です。

`epd_dashboard_render_labeled()` は同じ配置に時刻基準の説明を追加します。
`caption` は 85 文字以内の ASCII、`right_label` は 4 文字以内です。
Card は未知の電源断時間を含む履歴を「現在の24時間」として継ぎ足さず、
保存セッションには `CLOCK UNKNOWN`、右端には `LAST` を表示します。

## Zephyr への組み込み

`epd3in6e` とこのディレクトリをアプリの CMake に追加します。
Zephyr 設定は `CONFIG_CPP=y` と、`snprintf()` で小数を表示するための `CONFIG_PICOLIBC_IO_FLOAT=y` が必要です。
C++ 標準ライブラリ、例外、動的メモリ確保は使いません。
パネルの電源、初期化、リフレッシュ、スリープは呼び出し元で操作してください。

## 確認

144 点の表示、時間軸の目盛り、保存セッションの説明が画面内に収まることをホスト描画で確認しました。
CSV と履歴のテストは `card/firmware/tests/run_storage_tests.sh` で実行できます。
欠測を含む履歴については、全欠測、途中の欠測区間、単独の最新サンプル、最新値の欠測、
最新値の実数上書き、従来の全有効データとの互換性、不正入力時のフレーム保護をホストで確認しました。
